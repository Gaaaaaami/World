API Reference

This reference covers every public type exposed by the VoxelTerrain module: the data structs that flow through the pipeline, the CPU noise generator, the Transvoxel mesher, the streaming terrain component, the custom scene proxy, the demo interaction actor and the module bootstrap.

Reading guide. Types are listed from low-level data upwards. If you only want to get terrain on screen, read Getting Started first, then UVoxelTerrainComponent.

Design Conventions

The whole module is built on three conventions. Understanding them makes every signature below predictable.

Coordinate spaces

Space Unit Meaning
Chunk coordinate chunk FChunkKey.X/Y/Z, integer chunk index. Multiply by ChunkSize * VoxelSize (6400 cm at LOD0) to get world units.
Voxel (local) coordinate voxel Integer sample index inside a chunk. Valid range is -1 … ChunkSize+1 because of the halo.
Local mesh space cm Vertex positions produced by the mesher, relative to the chunk origin.
World space cm Local mesh space plus the chunk world origin. This is what the GPU receives.

Weight convention

Density is stored as FVoxelWeight (int8) in the range [-128, 127]. A voxel is solid when its weight is negative (FVoxel::IsSolid()). The mesher interpolates the zero crossing on every edge, so the sign — not the magnitude — decides the surface. Magnitude only controls where along the edge the vertex lands.

Threading contract

Member family Owning thread Rule
Every TMap / TSet on the component (ChunkMeshes, ChunkVoxelData, ChunkVersions, RequestedChunks, …) Game thread Never touch from a worker task.
UVoxelTerrainComponent::StreamTick, OnChunkGenerated, ApplyEdit, ProcessCollisionQueue Game thread Driven by core tickers or Blueprint.
UVoxelGenerator::GenerateChunk, FTransvoxelMesher::GenerateRegular Any worker thread Pure functions, no UObject mutation.
FVoxelSceneProxy::AddChunk_RenderThread / RemoveChunk_RenderThread Render thread Must be reached through ENQUEUE_RENDER_COMMAND.
UVoxelGenerator::GlobalNoiseLayers / GlobalNoiseLayers3D Written once in BeginPlay, read-only afterwards Safe to read concurrently.

Background tasks capture TWeakObjectPtr only, so an in-flight task silently becomes a no-op if the component or the generator is destroyed first. Results are marshalled back with AsyncTask(ENamedThreads::GameThread, ...).

Getting Started

1. Module dependency

Add the module to your game project's *.Build.cs. Every public header is exported with VOXELTERRAIN_API, so no further include path tweaks are needed.

PublicDependencyModuleNames.AddRange(new string[]
{
    "VoxelTerrain",
    "ProceduralMeshComponent",   // collision pool
});

TransvoxelMesher.cpp includes Transvoxel.h, which is a header-only table file (the Lengyel Transvoxel lookup tables). The module startup touches sizeof(regularCellClass) purely to force the tables to be linked in — no runtime cost beyond that.

2. Drop a component on an Actor

// In any AActor subclass, or simply add it in the Blueprint editor.
UVoxelTerrainComponent* Terrain = CreateDefaultSubobject<UVoxelTerrainComponent>(TEXT("Terrain"));
Terrain->SetMobility(EComponentMobility::Movable);

Then in the Details panel assign Terrain Material. Any opaque surface-domain material works; the mesh supplies position, normal, tangent, one UV channel and vertex colour. If you leave it empty the engine default surface material is used.

3. Minimal terrain with noise textures

  1. Create two square, power-of-two, uncompressed textures (G8, BGRA8 or RGBA8), at least 4×4. Disable mip maps and set them not to be texture-streamed — the CPU reads mip 0 on BeginPlay.
  2. Add them to Noise Layers (2D) and/or Noise Layers 3D (cubic UVolumeTexture).
  3. Tune Frequency / Amplitude. The 2D layers shape the surface height; the 3D layers carve caves.
// C++ equivalent
FVoxelNoiseLayerInfo Layer;
Layer.Texture   = LoadObject<UTexture2D>(nullptr, TEXT("/Game/Noise/T_Continental"));
Layer.Frequency = 1.0f;
Layer.Amplitude = 1.0f;
Layer.Offset    = FVector2D(0.f, 0.f);
Terrain->NoiseLayers.Add(Layer);

4. Choose streaming radii

LOD0 Radius XY (Chunks) and LOD0 Radius Z (Chunks) are chunk counts, not metres. At LOD0 one chunk spans 6400 cm, so the defaults (8, 8, 2) cover roughly ±512 m horizontally and ±128 m vertically — 17×17×5 = 1445 chunks. Raise them only after you have measured FTransvoxelMesher::GenerateRegular, because generation cost grows with the cube of the radius.

5. Dig and fill

// BlueprintCallable — safe to call from a line trace result.
Terrain->ApplyEdit(Hit.Location, 150.f, /*bIsAdd=*/false); // carve
Terrain->ApplyEdit(Hit.Location, 150.f, /*bIsAdd=*/true);  // raise

Or place an AVoxelInteractionActor in the level: left mouse carves, right mouse fills, driven by a cooldown and a visibility-channel line trace.

6. Recommended starting values

Setting Value Why
LOD0 Radius XY (Chunks) 4–8 17³ → 1445 chunks is already a lot of CPU mesh data.
LOD0 Radius Z (Chunks) 1–2 Terrain is usually a thin slab.
Unload Delay 2.0 s Prevents thrashing when the player walks back and forth across a boundary.
Collision Radius (1,1,1) 27 UProceduralMeshComponents. Each one cooks a collision mesh — this is the single most expensive part of streaming.
bGenerate Collision false while prototyping Removes the whole collision pool from the profile.
Edit Cooldown (interaction actor) 0.1 s ApplyEdit is synchronous.

Data Types

FVoxel

One sample of the scalar density field. Defined in VoxelTypes.h.

Field Type Description
Weight FVoxelWeight (int8) Signed density. Negative = solid, positive = air, zero = exactly on the isosurface.
Material uint8 Reserved surface material id. Currently written but not read by the mesher. 
FORCEINLINE bool IsSolid() const;   // Weight < 0

VoxelConfig

Compile-time constants. Changing ChunkSize or VoxelSize invalidates saved data and the halo maths — treat them as fixed.

Constant Value Description
ChunkSize 64 Cells per chunk per axis.
ChunkStride 65 ChunkSize + 1 — sample points per axis inside a chunk.
PaddedStride 67 ChunkStride + 2 — includes the ±1 halo.
PaddedOffset 1 Index shift so that local coordinate -1 maps to slot 0.
VoxelSize 100.f World size of one voxel, in cm.

Derived numbers worth memorising: one LOD0 chunk is 6400 cm across; the padded voxel grid holds 67³ = 300 763 samples; the surface grid holds 67² = 4489 columns.

FChunkKey

Identity of a chunk. Four int32 fields: X, Y, Z, LOD. Provides operator== and a free GetTypeHash, so it can be used directly as a TMap / TSet key.

FChunkKey Key(3, -1, 0, 0);   // LOD defaults to 0

LOD scaling rule: a chunk at LOD N covers 1 << N LOD0 chunks per axis, and its world size is ChunkSize * VoxelSize * (1 << N). Only LOD 0 is currently generated by the streaming loop; the LOD fields and the shift maths are already in place (SpawnChunkAsyncTask computes LODChunkWorldSize correctly), but StreamTick never requests LOD > 0.

FVoxelEditTask (WorldPos, Radius, bIsAdd) and FVoxelModificationMap (TMap<FIntVector, FVoxelWeight>) are declared in the same header. Both are currently unused — the modification-map pipeline is commented out, and ApplyEdit writes straight into the cached voxel data.

FVegetationInstanceData

Plain output record of the scatter pass.

Field Type Description
Location FVector World-space spawn position.
Rotation FRotator Random yaw, zero pitch/roll.
Scale FVector Uniform scale, per instance.
PlantId int32 Index into VegetationConfigs.

FVoxelChunkData

CPU-side storage for one chunk: the padded density cube plus a per-column surface height.

Field / Method Description
TArray<FVoxel> Voxels PaddedStride³ samples, zero-initialised by the constructor.
TArray<float> SurfaceGrid PaddedStride² heights, one per (ix, iy) column. Not initialised by the constructor — every reader must overwrite it (the generator does).
int32 Index(x, y, z) Flat index. Equivalent to ((x+1)*N + (y+1))*N + (z+1).
FVoxel& At(x, y, z) Mutable access. Valid range -1 … ChunkSize+1.
const FVoxel& At(x, y, z) Const overload.
float& SurfaceAt(ix, iy) Mutable surface height. The index maths uses ix * PaddedStride + iy.
float SurfaceAt(ix, iy) Const overload. 
FVoxelChunkData Chunk;
Chunk.At(0, 0, 0).Weight = -127;     // solid
Chunk.SurfaceAt(4, 9) = 1234.5f;

SurfaceAt(ix, iy) is not bounds-checked and ix is multiplied by PaddedStride, not by PaddedStride² — pass padded-local indices (0 … 66), never chunk-local ones.

FVoxelMeshData

The interchange struct between the mesher, the game thread and the render thread.

Field Type Description
Positions TArray<FVector3f> Local-space vertex positions (chunk origin subtracted).
Normals TArray<FVector3f> Central-difference gradient of the density field.
UVs TArray<FVector2f> Planar XY / 400.f, filled by the component after meshing.
Colors TArray<FColor> Biome/height vertex colour, see ComputeColor.
Indices TArray<uint32> Triangle list, always 32-bit.
Bounds FBox World-space bounds, precomputed off-thread so the main thread only merges.
Method Description
void Reset() Empties every array (Reset, capacity kept) and re-inits Bounds.
int32 NumTriangles() const Indices.Num() / 3.

SurfaceHeights still exists as a commented-out field, together with the UV1 channel that used to carry it. The vertex factory is therefore bound to one UV channel.

Copy cost: ApplyEdit pushes a deep copy (MakeShared<FVoxelMeshData>(MeshData)) to the render thread, because the game-thread copy stays editable.

Instance API

Method Description
void GenerateChunk(int32 ChunkX, int32 ChunkY, int32 ChunkZ, int32 LOD, FVoxelChunkData& OutChunk) const Fills the whole padded grid, including the halo, and writes every column's surface height. Pure — safe on any thread. Cost is dominated by one TexFbm2D per column plus one density sample per voxel.
virtual float SampleDensityWithSurface(const FVector& WorldPos, float SurfaceZ) const Signed density in cm. Above the surface it returns SurfaceZ - WorldPos.Z, then carves caves with SmoothMax over two 3D texture lookups and converts noise distance to world units via 1 / (NoiseFreq * 0.7).
virtual float Fbm(const FVector& P) const Normalised 3D Perlin FBM, seed-offset.
virtual float Fbm2D(const FVector2D& P) const Normalised 2D Perlin FBM, seed-offset.
virtual float TexFbm2D(const FVector2D& WorldXY) const Amplitude-weighted blend of GlobalNoiseLayers; falls back to Fbm2D(WorldXY * NoiseFreq) when no layers are loaded.
virtual float TexFbm3D(const FVector& WorldXYZ) const Same for GlobalNoiseLayers3D; falls back to Fbm.

Every method is virtual, so subclassing UVoxelGenerator and overriding SampleDensityWithSurface is the supported way to change world shape without touching the mesher.

VOXEL_USE_NOISE_TEXTURE

Defined to 1 at the top of VoxelGenerator.h. Set it to 0 (or add a project-level definition) to compile the texture path out entirely and run on analytic Perlin only.

Meshing

FTransvoxelMesher

Stateless utility, VOXELTERRAIN_API. Both entry points are static.

GenerateRegular

static void GenerateRegular(const FVoxelChunkData& Chunk,
                            float VoxelSize,
                            int32 LOD,
                            const FVector3f& ChunkWorldOrigin,
                            FVoxelMeshData& Out);

Runs the modified Marching Cubes (regular-cell part of the Transvoxel algorithm) over all 64³ cells of one chunk.

Parameter Direction Notes
Chunk in Must be fully generated, halo included.
VoxelSize in Pass VoxelConfig::VoxelSize (100). Not multiplied by 1 << LOD — LOD scaling is applied to the world origin only.
LOD in Currently only affects WorldStep bookkeeping; vertex spacing stays VoxelSize.
ChunkWorldOrigin in Added to every local position.
Out in/out Reset() at entry, then filled.

Behaviour details worth knowing:

  • A thread_local edge cache (size 65³ × 3) deduplicates vertices across the six shared cell faces, so adjacent cells weld seamlessly. It is memset to -1 per call and grown on demand — one allocation per worker thread, ever.
  • Case bits follow the Transvoxel corner order: bit 0 = (0,0,0), bit 1 = (1,0,0), … bit 7 = (1,1,1). Weight W = 0 counts as not solid.
  • Normals come from central differences on the raw int8 weights, so they are blocky near flat regions and fall back to (0,0,1) when the gradient vanishes.
  • Output triangles are wound I0, I2, I1 to match UE's front-face convention.
  • Out.Bounds is not written here; the component computes it after applying the world offset.

GenerateRegularPartial

static void GenerateRegularPartial(const FVoxelChunkData& Chunk,
                                   float VoxelSize,
                                   const FVector3f& ChunkWorldOrigin,
                                   const FIntVector& CellMin,
                                   const FIntVector& CellMax,
                                   FVoxelMeshData& InOut);

Incremental rebuild used by terrain editing. Instead of re-meshing, it filters the existing mesh in place:

  1. Every triangle whose floor-space minimum cell falls inside [CellMin, CellMax] is dropped.
  2. Surviving vertices are compacted, remapped through an old-to-new index table, and all arrays are shrunk.
  3. Colors, Normals, UVs and Positions are preserved for surviving vertices.

CellMin / CellMax are chunk-local cell coordinates, inclusive, and must stay within 0 … ChunkSize-1. InOut is modified; if it has no indices the function resets it and returns. Because triangles are discarded by their own cell only, calling this with a box that does not exactly match the dirty region will leave seams — always derive the box from the same SDF bounds the component uses.

InOut.Bounds is stale afterwards; the caller must recompute it (ApplyEdit does).

Blueprint-callable / overridable

void ApplyEdit(const FVector& WorldPos, float Radius, bool bIsAdd) — BlueprintCallable, Category = "Voxel".

Stamps a spherical brush into the cached density of every overlapping chunk, plus a one-voxel halo in all 26 neighbours, then synchronously re-meshes the touched chunks, pushes them to the scene proxy and refreshes their collision section. bIsAdd == true adds material, false carves.

Contract notes:

  • Game-thread only, and blocking: the whole touched set is rebuilt before the call returns. Keep the radius modest.
  • Chunks that are not resident are skipped silently — editing outside the streaming radius is a no-op.
  • Every touched chunk's version is incremented first, so an async result that lands during the rebuild is discarded.
  • The mesh deep-copies into the render command, so the CPU copy stays mutable.

void StreamTick() — BlueprintNativeEvent, Category = "Voxel&#124;Streaming". Override in Blueprint and call Parent: StreamTick to keep the default behaviour.

Streaming heartbeat, driven by a ~0.16 s core ticker rather than per-frame tick. Each call:

  1. Enumerates the (2·XY+1) × (2·Z+1) chunk box around the local pawn; already-resident chunks just have their activity timestamp refreshed.
  2. Sorts the remaining candidates by squared distance and dispatches up to MaxRequestsPerTick async tasks — 8 by default, 16 above 20 m/s, 24 above ~31.6 m/s.
  3. Evicts chunks outside Radius + 1 whose idle time exceeds UnloadDelay, dropping mesh, voxel cache, timestamps, version, collision proxy and render-thread resource, then rebuilds LocalBounds from the survivors.

Note that LocalBounds is rebuilt from scratch every tick from the surviving chunks, so it never suffers from bounds drift after eviction.

Coordinate helper

FIntVector WorldToBaseChunk(const FVector& WorldPos) const;

Floor-divides by ChunkSize * VoxelSize (6400 at LOD0), so negative coordinates map correctly. This is the only place chunk size is turned into world size — always route through it.

Async pipeline

void SpawnChunkAsyncTask(const FChunkKey& Key, int32 CurrentVersion)

Dispatches one chunk to EAsyncExecution::ThreadPool. The worker:

  1. Calls GenerateChunk into a stack FVoxelChunkData.
  2. Runs FTransvoxelMesher::GenerateRegular into a new FVoxelMeshData.
  3. Offsets every position by the chunk world origin, computes planar UVs with UVScale = 400.f, and accumulates world Bounds.
  4. Moves the voxel data into a shared pointer and hops back to the game thread via AsyncTask.

Captures are weak (TWeakObjectPtr<UVoxelTerrainComponent> and TWeakObjectPtr<UVoxelGenerator>); a destroyed component makes the task a no-op at both checkpoints.

void OnChunkGenerated(FChunkKey Key, TSharedPtr<FVoxelMeshData, ESPMode::ThreadSafe> Mesh, TSharedPtr<FVoxelChunkData> VoxelData, int32 Version)

Game-thread completion handler.

  1. Clears RequestedChunks.
  2. Drops the payload if Version != ChunkVersions.FindRef(Key) — an edit happened while the task was in flight, and the synchronous rebuild wins.
  3. Stores mesh and voxel cache, stamps ChunkLastActiveTime, merges Bounds into LocalBounds.
  4. Enqueues AddChunk_RenderThread on the render thread.

This method is public, so you can call it yourself to inject a procedurally built chunk — as long as you respect the version check.

Noise texture loading

void LoadNoiseTextureData()

Reads every NoiseLayers / NoiseLayers3D texture into linear float arrays and publishes them to the generator's global layer arrays.

  • Editor path (WITH_EDITORONLY_DATA): reads Texture->Source.GetMipImage.
  • Packaged path: reads cooked platform mip 0 — PF_G8, PF_B8G8R8A8, PF_R8G8B8A8 only. Anything else is logged and skipped.
  • sRGB textures are linearised so both paths agree.

Textures must be square (cubic for 3D) and at least 4×4, and the bulk data must be CPU-readable — disable texture streaming and compression on them. Changing the arrays at runtime has no effect until the component restarts.

Interaction Actor

Usage Recipes

From a weapon hit

// On the server / in a single-player BlueprintCallable
FHitResult Hit;
if (TraceWeapon(Hit))
{
    if (UVoxelTerrainComponent* Terrain =
            Hit.GetActor()->FindComponentByClass<UVoxelTerrainComponent>())
    {
        // carve a crater, then let the collision tick catch up
        Terrain->ApplyEdit(Hit.Location, 200.f, false);
    }
}

ApplyEdit is synchronous, so spamming it every frame will stall the game thread. Rate-limit it the way AVoxelInteractionActor does.

Custom density function

UCLASS()
class UMyGenerator : public UVoxelGenerator
{
    GENERATED_BODY()
public:
    virtual float SampleDensityWithSurface(const FVector& P, float SurfaceZ) const override
    {
        // negative = solid
        return FMath::Sin(P.X * 0.001f) * 300.f + (SurfaceZ - P.Z) * 0.5f;
    }
};

Then set Voxel Generator Class = UMyGenerator on the component. BeginPlay will NewObject it for you.

Reading the mesh on CPU

if (const TSharedPtr<FVoxelMeshData, ESPMode::ThreadSafe>* M =
        Terrain->ChunkMeshes.Find(Key))
{
    const FVoxelMeshData& Data = **M;
    const int32 Tris = Data.NumTriangles();
    const FBox& Box  = Data.Bounds;   // already world-space
}

Positions are local to the chunk origin; add FVector(Key.X, Key.Y, Key.Z) * 6400.f to get world space.

Disabling collision

Set bGenerateCollision = false before BeginPlay, or toggle it at runtime — the next ProcessCollisionQueue tick (≤0.33 s) returns every pooled component.

设计约定

三条约定理解之后，下面每个签名都可预测。

坐标空间

空间 单位 含义
Chunk 坐标 chunk FChunkKey.X/Y/Z 整型索引；乘以 ChunkSize * VoxelSize（LOD0 为 6400 cm）得到世界单位
体素（局部）坐标 体素 chunk 内采样下标，因 halo 存在，有效范围 -1 … ChunkSize+1
局部网格空间 cm 网格化器输出、相对 chunk 原点的顶点位置
世界空间 cm 局部位置 + chunk 世界原点，GPU 实际收到的就是它

权重约定

密度存为 FVoxelWeight（int8），范围 [-128, 127]，负数为实体（FVoxel::IsSolid()）。网格化器在每条边的零值处插值，因此决定表面的是符号；数值大小只影响顶点在边上的位置。

线程契约

成员 归属线程 规则
组件上的 TMap/TSet（ChunkMeshes、ChunkVoxelData、ChunkVersions、RequestedChunks …） 游戏线程 后台任务不得访问
StreamTick、OnChunkGenerated、ApplyEdit、ProcessCollisionQueue 游戏线程 由核心 Ticker 或蓝图驱动
UVoxelGenerator::GenerateChunk、FTransvoxelMesher::GenerateRegular 任意工作线程 纯函数，不改动 UObject
AddChunk_RenderThread / RemoveChunk_RenderThread 渲染线程 必须经 ENQUEUE_RENDER_COMMAND 到达
GlobalNoiseLayers / GlobalNoiseLayers3D BeginPlay 写一次，之后只读 可并发读

后台任务只捕获 TWeakObjectPtr，组件或生成器先销毁时任务自动变为空操作；结果通过 AsyncTask(ENamedThreads::GameThread, ...) 送回。

快速开始

1. 添加模块依赖

PublicDependencyModuleNames.AddRange(new string[]
{
    "VoxelTerrain",
    "ProceduralMeshComponent",   // 碰撞对象池
});

Transvoxel.h 是纯头文件查找表（Lengyel Transvoxel 表）；模块启动读一次 sizeof(regularCellClass) 只为把表链入，无额外运行时开销。

2. 把组件挂到 Actor 上

UVoxelTerrainComponent* Terrain = CreateDefaultSubobject<UVoxelTerrainComponent>(TEXT("Terrain"));
Terrain->SetMobility(EComponentMobility::Movable);

在细节面板指定 Terrain Material（任意不透明表面材质；为空则用引擎默认材质）。网格提供位置、法线、切线、一组 UV 和顶点色。

3. 用噪声贴图生成地形

  1. 准备 正方形、边长 2 的幂、不压缩 的贴图（G8/BGRA8/RGBA8，≥4×4），关闭 mipmap 与流送——BeginPlay 在 CPU 上读 mip 0。
  2. 加入 Noise Layers（2D）和/或 Noise Layers 3D（立方 UVolumeTexture）。
  3. 调 Frequency / Amplitude：2D 层决定地表高度，3D 层挖洞穴。
FVoxelNoiseLayerInfo Layer;
Layer.Texture   = LoadObject<UTexture2D>(nullptr, TEXT("/Game/Noise/T_Continental"));
Layer.Frequency = 1.0f;
Layer.Amplitude = 1.0f;
Layer.Offset    = FVector2D(0.f, 0.f);
Terrain->NoiseLayers.Add(Layer);

4. 选定流式半径

LOD0 Radius XY/Z (Chunks) 单位是 chunk，不是米。LOD0 一个 chunk 为 6400 cm，默认 (8, 8, 2) 即水平约 ±512 m、垂直约 ±128 m，共 17×17×5 = 1445 个 chunk。生成开销随半径立方增长，调大前先测 GenerateRegular 耗时。

5. 挖与填

Terrain->ApplyEdit(Hit.Location, 150.f, false); // 挖
Terrain->ApplyEdit(Hit.Location, 150.f, true);  // 填

或在关卡放一个 AVoxelInteractionActor：左键挖、右键填。

6. 推荐起步参数

设置 值 原因
LOD0 Radius XY (Chunks) 4–8 1445 个 chunk 已是很大的 CPU 网格量
LOD0 Radius Z (Chunks) 1–2 地形通常是薄层
Unload Delay 2.0 s 防止边界来回走时反复加载/卸载
Collision Radius (1,1,1) 27 个 PMC，每个都要 cook 碰撞，是流式最贵的一环
bGenerate Collision 原型阶段关掉 直接从性能剖析里移除碰撞池
Edit Cooldown 0.1 s ApplyEdit 是同步调用

网格化

FTransvoxelMesher

无状态静态工具类。

GenerateRegular

static void GenerateRegular(const FVoxelChunkData& Chunk, float VoxelSize,
    int32 LOD, const FVector3f& ChunkWorldOrigin, FVoxelMeshData& Out);

对 chunk 全部 64³ 个 cell 执行改良 Marching Cubes（Transvoxel 规则单元部分）。

参数 说明
Chunk 必须已完整生成（含 halo）
VoxelSize 传 VoxelConfig::VoxelSize；不要自行乘 1 << LOD
LOD 当前只参与 WorldStep 记录，顶点间距仍为 VoxelSize
ChunkWorldOrigin 加到每个局部位置上
Out 入口处 Reset()，随后填充

实现要点：

  • thread_local 边缓存（65³×3）跨共享面复用顶点，相邻 cell 无缝焊接；每线程只分配一次。
  • Case 位序按 Transvoxel 角点：bit0=(0,0,0)、bit1=(1,0,0) … bit7=(1,1,1)；W = 0 视为非实体。
  • 法线为中心差分，梯度为零时回退 (0,0,1)。
  • 三角形绕序 I0, I2, I1 匹配 UE 正面判定。
  • 不写 Out.Bounds，由组件在施加世界偏移后计算。

GenerateRegularPartial

static void GenerateRegularPartial(const FVoxelChunkData& Chunk, float VoxelSize,
    const FVector3f& ChunkWorldOrigin, const FIntVector& CellMin,
    const FIntVector& CellMax, FVoxelMeshData& InOut);

编辑用增量重建：不重新网格化，而是就地过滤已有网格：

  1. 三角形最小角 cell 落在 [CellMin, CellMax] 内的丢弃；
  2. 存活顶点紧凑重排，索引经新旧映射表改写；
  3. 存活顶点的法线、UV、颜色原样保留。

CellMin/Max 为 chunk 局部 cell 坐标，闭区间，须在 0 … ChunkSize-1 内。范围与真实脏区不一致会留下接缝。调用后 InOut.Bounds 失效，调用方须重算（ApplyEdit 会做）。

蓝图可调用 / 可重写

ApplyEdit(const FVector& WorldPos, float Radius, bool bIsAdd) — BlueprintCallable, Voxel

球形笔刷写入所有相交 chunk（含 26 邻居的一体素 halo）的缓存密度，然后同步重建受影响 chunk、推入场景代理、刷新碰撞。bIsAdd 为 true 增材，false 挖除。

  • 仅游戏线程，阻塞调用，半径务必克制；
  • 未驻留 chunk 静默跳过；
  • 受影响 chunk 先自增版本，编辑期间落地的异步结果被丢弃；
  • 推渲染线程的是深拷贝。

StreamTick() — BlueprintNativeEvent, Voxel&#124;Streaming，可在蓝图重写并调用 Parent 保留默认行为。

约 0.16 s 核心 Ticker 驱动（非逐帧 Tick），每次：

  1. 枚举玩家周围 (2·XY+1)×(2·Z+1) 的 chunk 盒，已驻留的刷新时间戳；
  2. 其余候选按距离平方排序，每 Tick 最多派发 MaxRequestsPerTick 个异步任务：8（默认）/ 16（速度 >20 m/s）/ 24（>~31.6 m/s）；
  3. 卸载超出 Radius + 1 且空闲超过 UnloadDelay 的 chunk（网格、缓存、时间戳、版本、碰撞、RT 资源全部释放），并从幸存 chunk 全量重建 LocalBounds。

  • 编辑器路径读 Source.GetMipImage；打包路径读平台 mip 0，仅 PF_G8/PF_B8G8R8A8/PF_R8G8B8A8；
  • sRGB 自动线性化，两条路径结果一致；
  • 贴图须正方形（3D 为立方）、≥4×4，且 CPU 可读（关流送、关压缩）；运行时改动需重启组件生效。

UCLASS()
class UMyGenerator : public UVoxelGenerator
{
    GENERATED_BODY()
public:
    virtual float SampleDensityWithSurface(const FVector& P, float SurfaceZ) const override
    {
        return FMath::Sin(P.X * 0.001f) * 300.f + (SurfaceZ - P.Z) * 0.5f; // 负=实体
    }
};

组件上设 Voxel Generator Class = UMyGenerator 即可。
